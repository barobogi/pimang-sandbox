2. `경복궁.png`: 경복궁 전체 영역 상공 조감 (축선 및 전각 배치 현황).
3. `근정전이 떠있음.png`: **[문제 사례]** 근정전이 지형에 얹혀 공중부양된 현황(원인 미확정).
4. `근정전_위치수정.png`: **[1차 수정]** Y=0 지면 안착 및 월대 정합 현황 (공중부양은 해결되었으나 중층 지붕/처마/비례 한계 잔존).

8. `청계천 물길 건물사이로 흐르게 조정 필요.png`: 건물 사이로 수로 선형이 자연스럽게 이어지지 못하고 덮이는 문제.
9. `청계천은 가려서 잘 안보임.png`: 3D 건물군에 가려 수면과 음각 수로 식별이 불가능한 현황.
10. `지도위에 글자가 너무 가려서 지도 확인이 방해됨.png`: 3D 지도 앵커 라벨들이 수로와 전각 위를 덮어 시야를 가리는 현황.

## 2. 현재 품질 정량 평가 (외부 객관 평가)

### ① 경복궁 근정전 (수정 후: 통과 3/9 항목)
- **통과 항목 (3개)**:
  - ✓ 지면 안착 (Y=0 스냅, 공중부양 해결)
  - ✓ 석조 기단(월대) 노출
  - ✓ 난간 조형 안착
- **미통과 항목 (6개 - 이번 수정 필수)**:
  - ✗ 중층 지붕 (현재 단층으로 보임 → 상하 2단 팔작지붕 구조 필수)
  - ✗ 처마 곡선 (현재 평평함 → 오공간 상승 곡률 처마 구현)
  - ✗ 기와골 질감 (흑회색 전통 기와 질감 강화)
  - ✗ 근정문 대비 크기 비율 (현재 앞의 근정문과 크기가 비슷함 → 공식 제원 기준 비율(출처 표기) 준수 필요)
  - ✗ 주변 전각 이름별 구분 미흡
  - ✗ 담장 석축 재질 미흡

### ② 청계천 단면음각 수로 (단독 뷰: 통과 2/6 항목)
- **통과 항목 (2개)**:
  - ✓ 물길 수면 식별
  - ✓ 흰 구간(다리로 보임) 식별
- **미통과 항목 (4개 - 이번 수정 필수)**:
  - ✗ 음각 단차 (지반 아래 -2.5m 쑥 꺼진 실제 하천 단면 미흡, 상자 돌출형태 탈피 필요)
  - ✗ 실제 선형 대조 불가 (현재 일정 폭의 직선형 → 완만하게 휘어지는 실제 자연 하천 선형 필수)
  - ✗ 라벨 가림
  - ✗ 종로구 동측 경계 밖 연장 오류 (구 경계 bbox 클립 필요)

## 3. 청계천 공식 실측 데이터 (Overpass OSM 기준)

- **원천 데이터**: OpenStreetMap `waterway=river` (Way ID: `368276771`, ODbL)
- **실측 제원**:
  - 종로구 구간 정점: **33개 정점 (WGS84 [lng, lat])**
  - 양 끝 직선거리: **약 2,711m** (청계광장 `126.9786, 37.5691` ~ 다산교 `127.0093, 37.5698`)
  - 방향: 정동서 (수평 2°)
  - 직선 이탈 편차: **최대 약 141m**
- **제작 지침**: 청계천 수로는 임의의 직선 박스로 모델링해서는 절대 통과할 수 없습니다. 반드시 첨부된 33정점 GeoJSON 중심선을 따라 수로와 양안 호안 옹벽을 배치하십시오.
